# split-handoff oracle (Lean 4)

`SplitHandoff/Spec.lean` is the executable reference semantics of the OpenSpec
capability `split-handoff`
(`openspec/changes/add-split-line-dealing/specs/split-handoff/spec.md`,
HO-001 to HO-068, read at commit `18cf3ee`). The state is the committee
handoff of LOOP item 41 as the board, the committee contract and the Node
Registry see it: the epochs (current, in grace, closed) with their rosters and
thresholds, the sharings each epoch holds (`x_f` per curve and the ECDSA
committee slots), the open handoff, the requests and their owning epochs, the
board's slot states, the handovers of the validator set, and the user records
that a handoff must not touch.

| Module | Holds |
|---|---|
| `SplitHandoff/Spec.lean` | `St`, `Handoff`, `Phase`, `EpochRec`, `Sharing`, `Req`, `Act`, `Op`, `Refusal`, `init`, `validGenesis`, `validState`, `refusals`, `effect`, `next`, `run`, `runOps`, `owner`, `ownsAt`, `validatorAt`, `qualified`, `armReady`, `signable` |
| `SplitHandoff/Tests.lean` | pins from the scenarios (`decide +kernel` and `#guard`) through ROTATE, carry, READY, arm, activation, queue, grace end, abort, armed abort and sweep |
| `SplitHandoff/Theorems.lean` | the invariant `Inv` of every reachable state and the theorems of the claims below |
| `SplitHandoff/Audit.lean` | `#print axioms` of every theorem and `#audit_ns SplitHandoff`, pinned (generated by `../scripts/gen_audit.py`) |
| `Main.lean` | the codec only, through `../codec` |

Build and gates (from `formal/lean-split`, under `heavy-run`):

    (cd handoff && lake build --wfail)
    ./gates.sh oracle handoff
    ./gates.sh trace handoff

## Modes

Default: one `kink-implementation/1` request with
`inputs = {"params", "genesis", "ops"}`, `params = {"delta_rot", "delta_grace",
"delta_sweep", "delta_cw"}` and `genesis = {"roster", "n", "f", "q", "t", "xf",
"users", "addrs"}`. A genesis outside the domain (`f ≥ 1`, `n ≥ 3f + 1`,
`q = ⌊(n + f + 2) / 2⌋`, `t = n − f`, `n` distinct seats) gives
`{"end": "could-not-apply", "reason": "outside-capability"}`. Otherwise the
answer is `{"end": "final", "cells": {"state", "obs"}}`, the end state of the
run from `init` and one observation per operation. A refused operation is the
observation `{"refused": CODES}` and changes nothing; the run goes on.

`--step`: JSON Lines `{"state", "op"}` to `{"state", "obs"}`; a refused
operation gives `{"refused": CODES}`; a state outside `validState` (the current
epoch is not current, a second current epoch, an epoch in grace other than the
one before the current one, `last_batch` above `mh`, a sharing of a later
epoch) gives `{"refused": ["outside-state-domain"]}`; a line that does not
decode gives `{"error": TEXT}`.

Every operation is `{"op", "actor", ...}`; the actor must be the operation's
own (ledger 2):

| Actor | Operations |
|---|---|
| `governance` | `rotate` |
| `target` | `eks`, `complaint(dealer)`, `ready(seat, q, h_s)` |
| `source` | `carry(dealer, ok)` |
| `board` | `arm(sigs)`, `block`, `order(rid, bind, slots)`, `end_req(rid)`, `use_slot(rid, a, i, tk)`, `sweep_ready(e)` |
| `contract` | `activate(gov, sigs, heartbeat, boots, disjoint)`, `submit_checkpoint(e, sigs)`, `cert(e)` |
| `time` | `midnight_tick(m)` |
| `seat` | `restart_begin`, `restart_end`, `admit_boot(seat, with_rotate)`, `entry(rid, e)`, `header(rid, pool_epoch)`, `envelope(e)`, `sign_checkpoint(e, board_height)` |
| `user` | `user_ack(u)`, always refused (HO-058) |

The clocks count Midnight blocks (`mh`, moved by `midnight_tick`); `pos` is the
board position. Phases: `IDLE`, `QUEUED`, `ROTATING`, `ARMED`, `HANDED_OVER`,
`ABORTED`; epochs are `current`, `grace` or `closed`.

## Claims

`ho056_*`, `ho057_*`, `ho058_*`, `ho036_*`, `ho059_*`, `ho044_*`, `ho035_*` and
`ho_no_source_after_arm` hold for every state; `ho063_*` for every state that meets
the invariant `Inv`; the others for every state reachable from a genesis
(`Reach s`), through `reach_inv`. `#print axioms` of each is `propext`,
`Classical.choice` and `Quot.sound` or fewer.

| Theorem | Statement |
|---|---|
| `ho056_xf_unchanged`, `ho056_run_xf` | every operation, and every run, keeps `X_f` per curve and each address's `(X_f, shard)` |
| `ho057_user_untouched` | every operation keeps every user record and every address |
| `ho058_no_user_action` | an accepted operation is never a user's |
| `ho_exposure_bound` | with at most `t − 1` corrupt or exposed seats in each committee (`hdual`, ledger 27), the adversary holds at most `t − 1` shares of every sharing |
| `ho032_authority_switch` | while ARMED `pos = H` and `block` is refused, the validator up to `H` is the source; when the activation is final the validator is unchanged up to `H` and is the target above `H` |
| `ho_no_source_after_arm` | from ARMED an honest activation before `m_D` reaches HANDED_OVER, it is no source operation, and every operation that reaches HANDED_OVER is the contract's |
| `ho059_one_owner` | a request has exactly one owning epoch at every position |
| `ho036_owner_switch` | the owning epoch is the binding epoch below the sweep position and the successor from it |
| `ho044_carried_slot_board_state`, `ho044_sweep_installs_board_state` | a carried slot is installed with the board's state, at the activation and at the sweep |
| `ho035_abort_keeps_old` | an abort from ROTATING or ARMED keeps the current epoch, the epochs, the sharings, the handovers, the landed epoch, the board and `pos` |
| `ho066_armed_abort` | when an ARMED handoff becomes ABORTED the validator is unchanged at every position, it is the source above `H`, and `block` is accepted again |
| `ho_start_from_any` | a valid ROTATE whose source is current is ROTATING or QUEUED, and a QUEUED one becomes ROTATING after operations of seats and time only |
| `ho_completes` | from ROTATING with no restart, `t` honest carries, a tick past the last complaint window (`hsync`, ledger 28), `n' − f'` READY posts, the arm and the activation reach HANDED_OVER by `m_D` with no user operation |
| `ho063_signable_preserved`, `ho063_run_signable` | every operation and every run keeps a signable address signable |
| `ho055_two_epochs` | every live epoch is the current one or the one before it, and none is in grace while ROTATING or ARMED |

Spec mutants (`mutants.json`): one per theorem; each fails `lake build
--wfail` at the theorem or at a pin.
