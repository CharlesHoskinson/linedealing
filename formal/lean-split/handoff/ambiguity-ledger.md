# Ambiguity ledger: split-handoff

One ledger for the capability, shared by the Lean oracle (this package) and a
later Quint model. Each entry is a sentence of
`openspec/changes/add-split-line-dealing/specs/split-handoff/spec.md` that
admits more than one reading, a case the oracle must answer and the spec does
not state, or a premise of a theorem that no sentence states. Where the spec is
silent, the oracle refuses and the entry says with which code.

- **Status.** `open`: no ruling yet. `ruled`: the spec owner chose a reading.
  `held`: a reading is applied until a ruling replaces it.
- **Gate.** `gates.sh oracle handoff` fails while any entry is `open`.
- **Spec version.** The commit the entry was read at.
