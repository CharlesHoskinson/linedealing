# Ambiguity ledger: split-shard-holders

One ledger for the capability, shared by the Lean oracle (this package) and the
Quint model of LOOP item 14. Each entry is a sentence of
`openspec/changes/add-split-line-dealing/specs/split-shard-holders/spec.md`
that admits more than one reading, or a case the oracle must answer and the
spec does not state. Where the spec is silent, the oracle refuses and the entry
says with which code.

- **Status.** `open`: no ruling yet. `ruled`: the spec owner chose a reading.
  `held`: a reading is applied until a ruling replaces it.
- **Gate.** `gates.sh oracle shard-holders` fails while any entry is `open`.
- **Spec version.** The commit the entry was read at.
